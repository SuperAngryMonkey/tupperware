# Tupperware v0.2.2 Release Notes

**HTTP Basic Auth for the web app.** One auth file on the host turns on authentication for every route — the HTML UI, the `/api/*` JSON routes, `/clone-stream`, and `/transfer-stream`. The MCP client authenticates with two environment variables.

## Enabling auth

Create the auth file on the Proxmox host (default path `/root/.tupperware/auth`, override with `TUPPERWARE_AUTH_FILE`):

```bash
mkdir -p /root/.tupperware
python3 -c "from werkzeug.security import generate_password_hash as g; \
    import getpass; print('admin:' + g(getpass.getpass()))" > /root/.tupperware/auth
chmod 600 /root/.tupperware/auth
systemctl restart tupperware
```

The file holds one line, `username:werkzeug-hash` — the password is never stored in plaintext. The file is re-read on change (mtime check), so rotating credentials does not require a restart.

## Behavior

- **File present** — every request must carry valid HTTP Basic credentials; anything else gets `401` with a `WWW-Authenticate` challenge. Browsers prompt natively.
- **File absent** — the app runs unauthenticated exactly as before v0.2.2, and logs a startup warning. Existing installs keep working when you redeploy.
- **File malformed or unreadable** — the app fails closed and refuses all requests (it never silently drops to unauthenticated).

Comparisons use `hmac.compare_digest` and werkzeug's `check_password_hash`.

## MCP client

`mcp/tupperware_mcp.py` reads two new environment variables and sends them as Basic auth on every request:

```json
"env": {
  "TUPPERWARE_URL": "http://<host>:8080",
  "TUPPERWARE_USER": "admin",
  "TUPPERWARE_PASS": "<password>"
}
```

Leave them unset against an un-authed web app; set both once the auth file exists.

## Notes

- Basic auth sends credentials with every request; the transport is still plain HTTP. This adds a credential gate on top of the tailnet-only access model — it is not a substitute for it. Keep the app off untrusted networks.
- One credential pair per install (single-line auth file), by design.

## Files changed

- `webui/app.py` — auth file loading, `before_request` gate, startup warning
- `mcp/tupperware_mcp.py` — `TUPPERWARE_USER` / `TUPPERWARE_PASS` support
