# Tupperware v0.2.5 Release Notes

**Interface pinning.** New `TUPPERWARE_BIND` environment variable selects the listen address for the web app (default `0.0.0.0`, unchanged). Set it to a tailscale or LAN interface address to pin an instance to that interface only.

Use it when a single interface is the right scope. When the app must answer on more than one internal interface (e.g. LAN **and** tailnet) but never externally, keep the default bind and scope the port with a host firewall rule instead, e.g. nftables:

```
tcp dport 8080 ip saddr { 127.0.0.0/8, <lan-subnet>, 100.64.0.0/10 } accept
tcp dport 8080 counter drop
```

## Files changed

- `webui/app.py` — `TUPPERWARE_BIND` env for the listen address
